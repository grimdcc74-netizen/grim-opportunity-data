# GRIM Opportunity Hub — Feed pubblico verificato

Questo repository contiene il feed pubblico verificato di GRIM Opportunity Hub: opportunità lavorative VFX e di post-produzione a Milano, open call artistiche e scadenze.

Il file [`data/current.json`](data/current.json) è il feed utilizzato dal sito.

## Dati ammessi e informazioni vietate

Il repository deve contenere solo dati pubblici relativi alle opportunità.

Non devono mai essere inseriti CV privati, portfolio privati, numeri di telefono, email private, note personali, lettere di raccomandazione, password, API key, token o altre credenziali.

## Regole di aggiornamento

- Gli ID delle opportunità devono restare stabili negli aggiornamenti successivi.
- Per le opportunità lavorative deve essere preferito il link diretto del datore di lavoro o dell'ATS ufficiale.
